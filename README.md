# Callbot Averon — хранилище проекта

Главная страница хранилища (MOC). Отсюда ведут ссылки на все разделы.
Заметки ведёт Claude по итогам задач в проекте «Callbot Averon» и коммитит их сюда;
у вас они подтягиваются плагином Obsidian Git.

## Правила ведения

- Ссылки обычные markdown и относительные: `[текст](папка/файл.md)`. Так они работают и в Obsidian, и на GitHub.
- Имена файлов латиницей и без пробелов, заголовки внутри по-русски.
- Решение: новый файл в `decisions/` по [шаблону](templates/decision.md) и строка в [списке решений](decisions/README.md).
- Изменения за день: файл `changelog/ГГГГ-ММ-ДД.md` по [шаблону](templates/changelog-entry.md) и строка здесь в «Последних записях».
- Секреты, ключи, персональные данные сотрудников и клиентов сюда не пишутся.
